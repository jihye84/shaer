# 페르시아 시인 연표

사만 왕조부터 잔드 왕조까지 왕조 연표 위에 페르시아 고전 시인 20명(루다키~하테프)의 생존 시기와 대표작 연도를 표시한 웹앱입니다.

- 시인을 누르면 소개와 대표작이 나오고, 금색 표시는 작품을 지은 해(속 빈 표시는 추정 연도)입니다. 생몰년이 불확실한 쪽은 막대 끝이 흐려집니다.
- 시인 20명 모두의 작품 30편(장편은 발췌)을 구절별 페르시아어·로마자 발음·우리말 풀이와 세밀화풍 그림으로 감상할 수 있습니다.
- 운(카피예)은 색 밑줄, 후렴(라디프)은 점선으로 표시합니다.
- 낭독 음성 268개가 파일 안에 들어 있어 어느 기기에서나, 인터넷이 없어도 들립니다. eSpeak NG의 페르시아어 음성으로 로마자 발음을 읽어 만든 기계음이며, 기기에 페르시아어 음성이 있으면 설정에서 바꿀 수 있습니다.

원문 출처: Ganjoor 기반 공개 말뭉치(github.com/amnghd/Persian_poems_corpus). 바바 타헤르의 도베이티와 라비아 발히의 시는 널리 알려진 형태를 따랐습니다. 니자미·자미·사에브·비델·하테프·오베이드는 Ganjoor 데이터베이스(github.com/ganjoor/ganjoor-db)와 대조했습니다.
